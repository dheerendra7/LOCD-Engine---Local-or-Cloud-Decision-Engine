System & access

Manage this workspace's scoped access and inspect the capabilities actually reported by the running control plane.

API access

The key is kept in this page's memory only. It is not saved to local storage, sent to analytics, or embedded in URLs.

Tenant-scoped
No API key stored in this page.
Access scopes: read loads the console; decide runs decisions, simulations and hybrid validation; targets manages targets; telemetry records outcomes; execute submits dry-runs; admin saves, edits, deletes or rolls back custom policies. Keys need read plus the matching action scope, or admin, which covers every API operation. The API enforces all permissions server-side.

03 / Safety boundary

What this API Lab can and cannot do

The tool is designed to teach the request lifecycle without risking live infrastructure.

Allowed

Health, readiness, tenant-scoped status, target and policy reads, plus read-only policy simulation.

Not exposed

Target or policy writes, outcome recording, live provider probes, and live execution.

Credential handling

The existing page-memory API key is sent only as an authorization header. It is never shown in the request preview or URL.
